# eink_dashboard — DS_CRO_대시보드

오닉스 BOOX Poke3(6인치 전자잉크)를 회사 책상에 세워 두는 **업무 캘린더 + 독서 인용구** 대시보드.

```
┌──────────────────────────┐
│ 2026년 10월 27일 (화)       │
│ ┏━━━━━━━━━━━━━━━━━━━━━━┓ │
│ ┃ 다음 일정               ┃ │  ← 업무 캘린더 (55%)
│ ┃ 14:30 유관부서 협의     ┃ │     오늘 · 다가오는 일정
│ ┗━━━━━━━━━━━━━━━━━━━━━━┛ │
│ 오늘 / 다가오는 일정        │
├──────────────────────────┤
│ 책갈피                     │  ← 옵시디언 독서 인용구 (45%)
│ 밑줄 친 문장 …             │     07~17시 매시 정각에 바뀜
│            — 책, 저자     │
│      동기화 10/27 08:52   │
└──────────────────────────┘
```

- **회사 와이파이 없이 쓴다.** 아이폰 핫스팟을 잠깐 켰을 때 2주치 일정과 인용구 전체를 받아 기기에 저장한다.
  '오늘', '다음 일정', '지금 인용구'는 기기 시계로 계산하므로 오프라인에서도 맞다.
- **개인 정보는 이 공개 레포에 올라가지 않는다.** 일정과 인용구는 구글 Apps Script가 토큰을 확인한 뒤
  기기에 직접 건넨다. 레포에는 화면 코드와 예시 데이터만 있다.

## 구성

| 경로 | 역할 |
|---|---|
| `index.html`, `assets/` | Poke3 브라우저에 띄우는 화면 (GitHub Pages로 호스팅) |
| `manifest.webmanifest`, `sw.js` | 홈 화면 앱(전체 화면) 설정, 오프라인용 페이지 저장 |
| `android/` | Poke3 전용 홈 앱(APK). 위 웹페이지를 전체 화면으로 띄우고 기기를 제어한다 |
| `apps_script/` | 구글 계정에서 돌아가는 중계 스크립트. 업무 캘린더 읽기 + 인용구 저장·전달 |
| `obsidian_plugin/eink-quotes/` | 옵시디언 플러그인. Books 폴더 독서 노트를 Apps Script로 보낸다 |
| `data/demo.json` | `?demo=1` 로 열 때 쓰는 예시 데이터 |

```
[옵시디언 Books 폴더] ──플러그인(노트 저장 시)───▶ [Apps Script] ──▶ 구글 드라이브에 인용구 저장
[구글 캘린더 '업무'] ─────────────────────────────▶ [Apps Script]
                                                    │ 토큰 확인 후 일정 2주치 + 인용구
                                                    ▼
                         [Poke3 브라우저] ── 핫스팟 연결 시 / 화면 탭 / 30분마다 동기화
```

## 설치

### 1. GitHub Pages 켜기
레포 **Settings → Pages → Build and deployment**
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)` → Save

1~2분 뒤 `https://nodeul99-dev.github.io/eink_dashboard/?demo=1` 에서 예시 화면을 볼 수 있다.

### 2. Apps Script 만들기 (업무 캘린더 + 인용구 중계)
1. https://script.google.com → **새 프로젝트**. 이름은 아무거나 (예: `eink_dashboard`)
2. **프로젝트 설정(⚙)** → `"appsscript.json" 매니페스트 파일을 편집기에 표시` 체크
3. 편집기에서 `Code.gs` 와 `appsscript.json` 내용을 이 레포의 `apps_script/` 파일로 통째로 바꾸고 저장
4. 함수 목록에서 **`setupToken`** 실행 → 권한 승인 (캘린더 읽기, 이 스크립트가 만든 드라이브 파일)
   → 실행 로그에 `TOKEN = ...` 이 나온다. 이 값을 따로 적어 둔다
5. **`listCalendars`** 실행 → 로그에서 업무 캘린더의 이름(또는 ID)을 확인
6. **프로젝트 설정 → 스크립트 속성**에 추가: `CALENDAR_NAME` = 업무 캘린더 이름
   (이름이 겹치면 `CALENDAR_ID` 를 대신 쓴다)
7. **`debugPayload`** 실행 → 로그에 오늘부터 2주치 업무 일정이 나오면 성공
8. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   → 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 적어 둔다

> 코드를 고친 뒤에는 **배포 관리 → 편집(연필) → 버전: 새 버전**으로 다시 배포해야 반영된다. URL은 그대로다.

'모든 사용자'는 URL을 아는 누구나 호출할 수 있다는 뜻이지만, 토큰이 틀리면 `unauthorized` 만 돌려준다.

### 3. Poke3 에 전용 앱 설치하기 (대시보드 전용 기기로 만들기)
Poke3를 대시보드 전용으로 쓰기 위한 앱이다. 화면은 위 웹페이지 그대로이고, 앱은 기기 제어만 한다.

- 상태바·하단 바 없는 **완전 전체 화면**, 화면 꺼짐 방지
- **홈 앱으로 지정**하면 전원을 켜거나 홈 버튼을 눌러도 항상 대시보드
- 화면을 **길게 누르면 관리 메뉴**: 지금 동기화 / 화면 잔상 지우기 / 다시 불러오기 / 와이파이 설정 /
  연결 파일 불러오기 / 연결 설정 (직접 입력) / 기본 홈 화면 바꾸기 / 기기 설정
- 매일 새벽 4시 이후 한 번 페이지를 다시 불러 화면 변경을 반영한다

설치:
1. Poke3 브라우저에서 아래 주소를 연다 → APK 다운로드
   ```
   https://github.com/nodeul99-dev/eink_dashboard/releases/latest/download/eink-dashboard.apk
   ```
2. 받은 파일을 열어 설치. '출처를 알 수 없는 앱' 경고가 나오면 이 브라우저에 설치 허용을 켠다
3. 재부팅하면 기본 홈 앱을 고르라고 나온다 → **DS_CRO_대시보드** → `항상`
   (안 나오면 앱을 한 번 연 뒤, 화면 길게 누르기 → `기본 홈 화면 바꾸기`)
   - BOOX 내비게이션 볼(화면 위 원형 버튼)은 제어 센터나 설정 → 내비게이션에서 끈다. 길게 누르기 메뉴가 대신한다
4. **연결 파일 넣기** (웹 앱 URL과 TOKEN을 Poke3에 전달)
   1. PC 메모장에 아래 한 줄을 적고 `dashboard.txt` 로 저장한다
      ```
      https://script.google.com/macros/s/<배포 ID>/exec?token=<TOKEN>
      ```
      (두 줄로 URL, TOKEN 을 따로 적어도 된다)
   2. Poke3를 USB로 PC에 연결(파일 전송) → `Download` 폴더에 복사
   3. Poke3 화면 길게 누르기 → `연결 파일 불러오기` → 저장소 권한 허용
      (파일을 못 찾으면 파일 선택 창이 뜬다 → dashboard.txt 를 고른다)
   4. 연결되면 `Download/dashboard.txt` 는 지운다 (토큰이 들어 있다)

   키보드로 직접 넣으려면 길게 누르기 → `연결 설정 (직접 입력)`.

업데이트: `android/` 를 고쳐 푸시하면 GitHub Actions가 새 APK를 같은 주소에 올린다. 1번을 다시 하면 덮어써진다.
화면(웹페이지)만 바뀐 경우는 재설치가 필요 없다.

원래 BOOX 홈 화면으로 돌아가려면: 길게 누르기 → `기본 홈 화면 바꾸기` → BOOX 런처 선택.

> 서명 키(`android/eink-dashboard.keystore`)는 개인용 사이드로드 앱이라 레포에 그대로 두었다.
> 같은 키로 서명해야 덮어쓰기 업데이트가 되기 때문이다.

### 3-1. 브라우저로만 쓸 때 (앱을 설치하지 않는 경우)
Poke3 브라우저에서 아래 주소를 **한 번** 연다 (`<...>` 부분을 바꿔서):

```
https://nodeul99-dev.github.io/eink_dashboard/#gas=<웹 앱 URL>&token=<TOKEN>
```

연결 정보는 기기에 저장되고 주소창에서는 바로 지워진다(`#` 뒤는 서버로 전송되지 않는다).
그다음부터는 `https://nodeul99-dev.github.io/eink_dashboard/` 만 열면 된다. 북마크해 둘 것.

연결을 지우려면 `...eink_dashboard/#reset=1` 을 연다.

### 4. 옵시디언 플러그인 (인용구 보내기)
독서 노트를 쓰는 옵시디언 안에서 인용구를 보낸다. PC와 Poke3는 직접 연결되지 않는다.
플러그인이 Apps Script(구글 드라이브)라는 **우편함**에 넣고, Poke3는 동기화할 때 거기서 꺼내 간다.

```
[옵시디언 (집 PC·회사 PC·아이폰 어디든)] ─ 노트 저장 시 ─▶ [Apps Script → 드라이브]  ◀─ 동기화 시 ─ [Poke3]
```

- 보내는 때: 옵시디언을 켤 때, Books 노트를 고친 뒤 1분이 지나면, 명령 팔레트 `인용구 지금 보내기`
- 내용이 지난번과 같으면 보내지 않는다. 기록이 Obsidian Sync로 공유돼 여러 기기가 중복으로 보내지 않는다
- 자동 전송이 실패해도(오프라인 등) 알림을 띄우지 않고 다음 기회에 다시 보낸다
- 처음 한 번은 Books 폴더 전체를 보낸다. 이후로도 매번 전체를 보내 우편함을 통째로 바꾸므로, 고치거나 지운 인용구도 반영된다

설치 (PC에서 한 번):
1. 옵시디언에서 볼트 폴더 열기: 왼쪽 아래 볼트 이름 → `볼트 관리` 또는 파일 탐색기에서 볼트 폴더로 이동
2. 볼트 폴더 안 `.obsidian/plugins/` 에 `eink-quotes` 폴더를 만든다
   (`.obsidian` 은 숨김 폴더다. 탐색기 `보기 → 숨긴 항목` 을 켠다)
3. 아래 두 파일을 받아 그 폴더에 넣는다 (링크에서 `Ctrl+S` 로 저장)
   - https://raw.githubusercontent.com/nodeul99-dev/eink_dashboard/main/obsidian_plugin/eink-quotes/manifest.json
   - https://raw.githubusercontent.com/nodeul99-dev/eink_dashboard/main/obsidian_plugin/eink-quotes/main.js
4. 옵시디언 `설정 → 커뮤니티 플러그인` → `제한 모드 끄기` → 설치된 플러그인 목록 새로고침(↻)
   → **DS_CRO 대시보드 인용구** 켜기
5. 그 플러그인의 설정(⚙):
   - `웹 앱 URL` 에 `https://script.google.com/macros/s/.../exec?token=...` 한 줄을 통째로 붙여 넣으면
     URL과 TOKEN이 알아서 나뉘어 들어간다
   - `독서 노트 폴더`: `Books` (볼트 안 실제 폴더 이름과 같게)
   - `지금 보내기 → 보내기` → `노트 N개 → 인용구 M개` 가 나오면 성공
6. 다른 기기에도 퍼지게: `설정 → 동기화` 에서 `설치된 커뮤니티 플러그인`,
   `활성 커뮤니티 플러그인 목록` 동기화를 켠다

### 5. Poke3 기기 설정
- 충전기를 계속 연결해 둔다
- 설정 → 전원: **자동 절전 끄기**, **자동 종료 끄기**, 화면 꺼짐 시간 최대/없음
- 설정 → 네트워크: 아이폰 핫스팟에 한 번 연결해 두면 이후 자동으로 다시 붙는다.
  절전 중 Wi-Fi 끄기 옵션이 있으면 끈다
- 아이폰: 설정 → 개인용 핫스팟 → **다른 사람의 연결 허용** 켜기
  (켜 두지 않으면 핫스팟 설정 화면을 열고 있을 때만 Poke3가 붙는다)
- 브라우저: 앱별 최적화에서 대비를 높이고 리프레시 모드는 `일반`(HD) 권장
- **전체 화면** (주소창·탭 없애기), 둘 중 하나:
  - **홈 화면에 추가 (권장)**: 브라우저 메뉴 → `홈 화면에 추가`(또는 `앱 설치`) → 홈 화면의 'DS_CRO' 아이콘으로 연다.
    처음부터 주소창 없이 열린다. Chrome에서 가장 잘 된다
  - **탭해서 전환**: 페이지를 한 번 탭하면 전체 화면이 된다(브라우저가 지원할 때). 브라우저를 다시 열면 한 번 더 탭
- 페이지 파일도 기기에 저장되므로(서비스 워커) 오프라인에서 브라우저가 다시 열려도 화면이 뜬다.
  인터넷이 되면 늘 새 파일을 받으므로, 레포에 푸시한 변경은 **다시 불러오기 한 번**에 반영된다
- 거치대에 세로로 세운다

**하루 사용 루틴**: 출근 후 핫스팟 켜기 → Poke3 화면 한 번 탭(즉시 동기화) → 상태 줄이 '방금'으로 바뀌면 핫스팟 끄기.
낮에 회의가 추가되면 그때만 다시 한 번.

> ⚠️ 회사에 따라 사무실 안 개인 핫스팟 사용을 금지하기도 한다(망분리 규정). 사내 지침을 먼저 확인할 것.
> 금지라면 집이나 출근길에 동기화하고 회사에서는 오프라인으로만 써도 된다. 2주치를 받아 두기 때문이다.

## 쓰는 법

### 일정 제목 규칙
- 업무 캘린더는 개인 구글 계정에 있으므로 제목은 회사 밖에 있어도 괜찮은 수준으로 적는다(내부 수치·거래명 금지).

### 화면 규칙
| 영역 | 동작 |
|---|---|
| 머리줄 | 날짜만 (시계 없음) |
| 다음 일정 | 오늘 아직 시작 안 한 가장 가까운 일정. 오늘 남은 게 없으면 '오늘 남은 일정 없음' (내일 이후는 안 보여줌) |
| 오늘 | 끝나지 않은 일정만. 진행 중이면 '진행 중', 끝난 건 제목 줄에 건수로 |
| 다가오는 일정 | 내일부터 받아 둔 2주치 끝까지 최대 6줄. 여러 날 걸친 일정은 첫날에만 |
| 책갈피 | 화면 아래 45%. 07~17시 매시 정각에 바뀐다(그 밖의 시간엔 17시 것을 유지). 제목 줄 버튼: `책 순서`↔`무작위` 전환, ↻ 다음(무작위면 아무) 문장. 책 순서는 노트 파일명 날짜순, 노트에 적힌 순서대로 이어 간다 |
| 상태 줄 | 맨 아래 오른쪽, 마지막 동기화 시각. 24시간이 넘으면 ⚠ |

화면은 10분마다 다시 계산하고(끝난 일정 걸러내기, 정각 인용구 교체), 바뀐 칸만 다시 그린다.

내용이 영역보다 길면 그 영역 글자만 줄어든다(최소 60%).

### 인용구 추출 규칙 (`apps_script/Code.gs` 의 `extractQuotes_`)
- 노트 파일명 `2026-07-13 ● (독서) 죽도록 즐기기, 닐 포스트먼.md` → 책 `죽도록 즐기기`, 저자 `닐 포스트먼`
- 빈 줄로 나뉜 인용 블록(`>`) 하나 = 인용구 하나
- 콜아웃(`> [!생각]` 등)은 직접 쓴 메모이므로 제외
- `**굵게**`, `==형광펜==` 은 굵게 표시. 링크·이미지·기울임 등 나머지 마크다운은 걷어낸다
- 300자를 넘는 인용구는 건너뛴다 (스크립트 속성 `QUOTE_MAX_CHARS` 로 조절)

### URL 옵션
| 옵션 | 뜻 |
|---|---|
| `?demo=1` | 예시 데이터로 보기 (연결 불필요) |
| `#reset=1` | 저장된 연결 정보·데이터 지우기 |

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 상태 줄 `동기화 실패 (오프라인)` | 핫스팟 연결 확인 후 화면 탭 |
| `unauthorized` | Poke3 에 넣은 TOKEN 이 스크립트 속성의 TOKEN 과 같은지. 다르면 `#gas=...&token=...` 주소로 다시 열기 |
| `work calendar not found` | 스크립트 속성 `CALENDAR_NAME`/`CALENDAR_ID` 철자 (`listCalendars` 로 확인) |
| 일정은 나오는데 인용구가 없음 | 플러그인 설정의 `지금 보내기` 결과가 `노트 N개 → 인용구 M개` 인지 |
| 플러그인 결과 `no quotes found` | `독서 노트 폴더` 이름이 맞는지, 노트에 `>` 인용 블록이 있는지 |
| `DriveApp` 권한 오류 | `appsscript.json` 의 `drive.file` 을 `https://www.googleapis.com/auth/drive` 로 바꾸고 다시 승인 |
| 코드를 고쳤는데 그대로 | Apps Script는 **새 버전으로 재배포**해야 반영된다 |
