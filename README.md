# eink_dashboard

오닉스 BOOX Poke3(6인치 전자잉크)를 회사 책상에 세워 두는 **업무 캘린더 + 독서 인용구** 대시보드.

```
┌──────────────────────────┐
│ 10월 27일 (화)      13:20 │
│ ┏━━━━━━━━━━━━━━━━━━━━━━┓ │
│ ┃ 다음 일정 · 1시간 10분 후 ┃ │  ← 업무 캘린더 (2/3)
│ ┃ 14:30 유관부서 협의     ┃ │     오늘 · 이번 주 · 마감 D-day
│ ┗━━━━━━━━━━━━━━━━━━━━━━┛ │
│ 오늘 / 이번 주 / 마감       │
│ 동기화 10/27 08:52 (4시간 전)│
├──────────────────────────┤
│ 옵시디언 독서기록 인용구      │  ← 인용구 (1/3)
│            — 책, 저자     │     07~17시 매시 정각에 바뀜
└──────────────────────────┘
```

- **회사 와이파이 없이 쓴다.** 아이폰 핫스팟을 잠깐 켰을 때 2주치 일정과 인용구 전체를 받아 기기에 저장한다.
  '오늘', '다음 일정까지 남은 시간', '지금 인용구'는 기기 시계로 계산하므로 오프라인에서도 맞다.
- **개인 정보는 이 공개 레포에 올라가지 않는다.** 일정과 인용구는 구글 Apps Script가 토큰을 확인한 뒤
  기기에 직접 건넨다. 레포에는 화면 코드와 예시 데이터만 있다.

## 구성

| 경로 | 역할 |
|---|---|
| `index.html`, `assets/` | Poke3 브라우저에 띄우는 화면 (GitHub Pages로 호스팅) |
| `apps_script/` | 구글 계정에서 돌아가는 중계 스크립트. 업무 캘린더 읽기 + 인용구 저장·전달 |
| `data/demo.json` | `?demo=1` 로 열 때 쓰는 예시 데이터 |

```
[옵시디언 books 폴더] ──아이폰 단축어(매일 아침)──▶ [Apps Script] ──▶ 구글 드라이브에 인용구 저장
[구글 캘린더 '업무'] ─────────────────────────────▶ [Apps Script]
                                                    │ 토큰 확인 후 일정 2주치 + 인용구
                                                    ▼
                         [Poke3 브라우저] ── 핫스팟 연결 시 / 화면 탭 / 30분마다 동기화
```

## 설치

### 1. GitHub Pages 켜기
레포 **Settings → Pages → Build and deployment**
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)` → Save

1~2분 뒤 `https://nodeul99-dev.github.io/eink_dashboard/?demo=1` 에서 예시 화면을 볼 수 있다.

### 2. Apps Script 만들기 (업무 캘린더 + 인용구 중계)
1. https://script.google.com → **새 프로젝트**. 이름은 아무거나 (예: `eink_dashboard`)
2. **프로젝트 설정(⚙)** → `"appsscript.json" 매니페스트 파일을 편집기에 표시` 체크
3. 편집기에서 `Code.gs` 와 `appsscript.json` 내용을 이 레포의 `apps_script/` 파일로 통째로 바꾸고 저장
4. 함수 목록에서 **`setupToken`** 실행 → 권한 승인 (캘린더 읽기, 이 스크립트가 만든 드라이브 파일)
   → 실행 로그에 `TOKEN = ...` 이 나온다. 이 값을 따로 적어 둔다
5. **`listCalendars`** 실행 → 로그에서 업무 캘린더의 이름(또는 ID)을 확인
6. **프로젝트 설정 → 스크립트 속성**에 추가: `CALENDAR_NAME` = 업무 캘린더 이름
   (이름이 겹치면 `CALENDAR_ID` 를 대신 쓴다)
7. **`debugPayload`** 실행 → 로그에 오늘부터 2주치 업무 일정이 나오면 성공
8. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   → 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 적어 둔다

> 코드를 고친 뒤에는 **배포 관리 → 편집(연필) → 버전: 새 버전**으로 다시 배포해야 반영된다. URL은 그대로다.

'모든 사용자'는 URL을 아는 누구나 호출할 수 있다는 뜻이지만, 토큰이 틀리면 `unauthorized` 만 돌려준다.

### 3. Poke3 에 연결하기
Poke3 브라우저에서 아래 주소를 **한 번** 연다 (`<...>` 부분을 바꿔서):

```
https://nodeul99-dev.github.io/eink_dashboard/#gas=<웹 앱 URL>&token=<TOKEN>
```

연결 정보는 기기에 저장되고 주소창에서는 바로 지워진다(`#` 뒤는 서버로 전송되지 않는다).
그다음부터는 `https://nodeul99-dev.github.io/eink_dashboard/` 만 열면 된다. 북마크해 둘 것.

연결을 지우려면 `...eink_dashboard/#reset=1` 을 연다.

### 4. 아이폰 단축어 (옵시디언 인용구 보내기)
옵시디언 Sync는 아이폰 안에 실제 파일을 두므로 단축어가 `books` 폴더를 읽을 수 있다.

단축어 앱 → **새 단축어** (이름 예: `인용구 보내기`)

1. **폴더 내용 가져오기**: `파일 → 나의 iPhone → Obsidian → (볼트 이름) → books`
2. **각 항목을 반복**
   1. **텍스트 가져오기**: 입력 = `반복 항목`  (노트 내용)
   2. **텍스트**: 아래처럼 세 줄로 적는다
      ```
      @@@FILE@@@ [반복 항목 → 이름]
      [텍스트]
      ```
3. **반복 끝** 다음에 **텍스트 결합**: `반복 결과`, 구분자 `새로운 줄`
4. **URL의 콘텐츠 가져오기**
   - URL: 웹 앱 URL
   - 방법: `POST`, 요청 본문: `JSON`
   - 필드 `token` (텍스트) = TOKEN, 필드 `bundle` (텍스트) = `결합된 텍스트`
5. (처음 확인용) **결과 보기** → `{"ok":true,"files":12,"quotes":340,...}` 처럼 나오면 성공

**자동화**: 단축어 앱 → 자동화 → 새로운 자동화 → **특정 시간**(매일 06:30) → `즉시 실행` → 위 단축어.
이후 Poke3가 다음 동기화 때 새 인용구를 받는다.

> `books` 안에 하위 폴더가 있으면 그 안의 노트는 읽히지 않는다(1단계가 폴더만 돌려준다). 노트는 `books` 바로 아래에 둘 것.

### 5. Poke3 기기 설정
- 충전기를 계속 연결해 둔다
- 설정 → 전원: **자동 절전 끄기**, **자동 종료 끄기**, 화면 꺼짐 시간 최대/없음
- 설정 → 네트워크: 아이폰 핫스팟에 한 번 연결해 두면 이후 자동으로 다시 붙는다.
  절전 중 Wi-Fi 끄기 옵션이 있으면 끈다
- 아이폰: 설정 → 개인용 핫스팟 → **다른 사람의 연결 허용** 켜기
  (켜 두지 않으면 핫스팟 설정 화면을 열고 있을 때만 Poke3가 붙는다)
- 브라우저: 전체 화면, 앱별 최적화에서 대비를 높이고 리프레시 모드는 `일반`(HD) 권장
- 거치대에 세로로 세운다

**하루 사용 루틴**: 출근 후 핫스팟 켜기 → Poke3 화면 한 번 탭(즉시 동기화) → 상태 줄이 '방금'으로 바뀌면 핫스팟 끄기.
낮에 회의가 추가되면 그때만 다시 한 번.

> ⚠️ 회사에 따라 사무실 안 개인 핫스팟 사용을 금지하기도 한다(망분리 규정). 사내 지침을 먼저 확인할 것.
> 금지라면 집이나 출근길에 동기화하고 회사에서는 오프라인으로만 써도 된다. 2주치를 받아 두기 때문이다.

## 쓰는 법

### 일정 제목 규칙
- 제목에 **`[마감]`** 또는 **`[D]`** 를 넣으면 '마감' 칸에 D-day로 센다 (60일 앞까지). 화면에서는 표시가 지워진다.
  예: `[마감] 분기 보고서 제출` → `D-2 분기 보고서 제출 10/29 (목)`
- 종일 일정으로 만든 마감은 그 날짜가 D-DAY다. 여러 날짜에 걸친 종일 일정은 마지막 날을 기한으로 본다.
- 업무 캘린더는 개인 구글 계정에 있으므로 제목은 회사 밖에 있어도 괜찮은 수준으로 적는다(내부 수치·거래명 금지).

### 화면 규칙
| 영역 | 동작 |
|---|---|
| 다음 일정 | 오늘 아직 시작 안 한 가장 가까운 일정. 남은 시간은 10분 단위로만 바뀐다(잔상 감소). 오늘 남은 게 없으면 다음 날 일정 |
| 오늘 | 끝나지 않은 일정만. 끝난 건 제목 줄에 건수로 |
| 이번 주 | 내일부터 일요일까지 최대 6줄. **금·토·일에는 '다음 주'**(다음 일요일까지)로 바뀐다. 마감 표시 일정은 '마감' 칸에만 |
| 마감 | 가까운 순 4개 |
| 인용구 | 07~17시 매시 정각에 바뀐다(그 밖의 시간엔 17시 것을 유지). 섞인 순서로 한 바퀴 다 돌기 전엔 반복되지 않는다 |
| 상태 줄 | 마지막 동기화 시각. 24시간이 넘으면 ⚠ |

내용이 영역보다 길면 그 영역 글자만 줄어든다(최소 60%).

### 인용구 추출 규칙 (`apps_script/Code.gs` 의 `extractQuotes_`)
- 노트 파일명 `2026-07-13 ● (독서) 죽도록 즐기기, 닐 포스트먼.md` → 책 `죽도록 즐기기`, 저자 `닐 포스트먼`
- 빈 줄로 나뉜 인용 블록(`>`) 하나 = 인용구 하나
- 콜아웃(`> [!생각]` 등)은 직접 쓴 메모이므로 제외
- `**굵게**`, `==형광펜==` 은 굵게 표시. 링크·이미지·기울임 등 나머지 마크다운은 걷어낸다
- 300자를 넘는 인용구는 건너뛴다 (스크립트 속성 `QUOTE_MAX_CHARS` 로 조절)

### URL 옵션
| 옵션 | 뜻 |
|---|---|
| `?demo=1` | 예시 데이터로 보기 (연결 불필요) |
| `?clock=0` | 시계 숨김 (매분 바뀌는 영역이 없어진다) |
| `#reset=1` | 저장된 연결 정보·데이터 지우기 |

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 상태 줄 `동기화 실패 (오프라인)` | 핫스팟 연결 확인 후 화면 탭 |
| `unauthorized` | Poke3 에 넣은 TOKEN 이 스크립트 속성의 TOKEN 과 같은지. 다르면 `#gas=...&token=...` 주소로 다시 열기 |
| `work calendar not found` | 스크립트 속성 `CALENDAR_NAME`/`CALENDAR_ID` 철자 (`listCalendars` 로 확인) |
| 일정은 나오는데 인용구가 없음 | 단축어를 한 번 실행했는지, 결과가 `ok:true` 인지 |
| 단축어 결과 `no quotes found` | 폴더 경로가 `books` 인지, 노트에 `>` 인용 블록이 있는지 |
| `DriveApp` 권한 오류 | `appsscript.json` 의 `drive.file` 을 `https://www.googleapis.com/auth/drive` 로 바꾸고 다시 승인 |
| 코드를 고쳤는데 그대로 | Apps Script는 **새 버전으로 재배포**해야 반영된다 |
