# eink_dashboard — DS_CRO_대시보드

오닉스 BOOX Poke3(6인치 전자잉크)를 회사 책상에 세워 두는 **업무 일정 + 독서 인용구** 전용 기기로 만든다.

```
┌───────────────────────────────┐
│ ■Schedule Board■  2026년 10월 27일 (화) │
│ ▍오늘          지난 일정 1건   │  ← 업무 일정 (55%)
│  14:30 유관부서 협의           │
│ ▍다가오는 일정                 │     오늘이 많으면 줄어듦 (최대 5줄)
│  10/28 (수) 10:00 임원 보고    │
├─────────────────────────────◣┤
│ “ 옵시디언 독서 노트에서        │  ← 책갈피: 밑줄 친 문장 (45%)
│   뽑은 인용구 …           ”    │     07~17시, 정한 간격마다 바뀜
│               — 책, 저자       │
│ ⚙ ↻              동기화 10/27 08:52 │
└───────────────────────────────┘
```

## 어떻게 동작하나

```
[구글 캘린더 'DS_업무'] ─────────────────────┐
                                           ▼
[옵시디언 Books 폴더] ─플러그인(노트 저장 시)─▶ [Apps Script 웹앱] ◀─ 동기화(핫스팟 연결 시·탭) ─ [Poke3 전용 앱]
 (집 PC·회사 PC·아이폰 어디서든)                  인용구 보관                                      화면 = GitHub Pages 웹페이지
```

- **회사 와이파이 없이 쓴다.** 핫스팟을 잠깐 켰을 때 2주치 일정과 인용구 전체를 받아 기기에 저장한다.
  '오늘', '지금 인용구'는 기기 시계로 계산하므로 오프라인에서도 맞다.
- **PC와 Poke3는 직접 연결되지 않는다.** Apps Script가 우편함 역할을 한다. 노트를 고칠 때 플러그인이 넣고, Poke3는 동기화할 때 꺼내 간다.
- **개인 정보는 이 공개 레포에 없다.** 일정·인용구는 Apps Script가 TOKEN을 확인한 뒤 기기에 직접 건넨다.

## 구성

| 경로 | 역할 | 바꾸면 할 일 |
|---|---|---|
| `index.html`, `assets/`, `sw.js`, `manifest.webmanifest` | 화면 (GitHub Pages) | 푸시 → Poke3에서 **길게 누르기 → 다시 불러오기** |
| `android/` | Poke3 전용 홈 앱 (웹페이지를 전체 화면으로 띄우고 기기 제어) | 푸시 → Actions가 APK 빌드 → 새 APK 덮어 설치 |
| `apps_script/` | 구글 계정의 중계 스크립트 (캘린더 읽기, 인용구 보관) | 편집기에 붙여 넣기 → **배포 관리 → 새 버전** |
| `obsidian_plugin/eink-quotes/` | 옵시디언 플러그인 (Books 노트를 Apps Script로 보냄) | 볼트의 `.obsidian/plugins/eink-quotes/` 파일 교체 |
| `data/demo.json` | `?demo=1` 예시 데이터 | — |

## 화면

| 영역 | 내용 |
|---|---|
| 머리줄 | 왼쪽 검은 상자에 제목(Apps Script 스크립트 속성 `TITLE`, 없으면 `Schedule Board`), 오른쪽 날짜 (시계 없음) |
| 오늘 | 끝나지 않은 일정(최대 6줄, 넘치면 '외 N건'). 진행 중이면 '진행 중', 끝난 건 제목 줄 오른쪽에 건수. 없으면 '오늘 남은 일정 없음' |
| 다가오는 일정 | 내일부터 2주치. 오늘 일정과 합쳐 7줄 안에서 최대 5줄 (오늘이 많으면 줄어듦, 최소 1줄). `MM/DD (요일)`, 여러 날 걸친 일정은 첫날에만 |
| 책갈피 | 메모지 모양(접힌 모서리, 큰 따옴표 무늬). 노트에서 굵게·형광펜 친 부분은 밑줄 |
| 맨 아래 줄 | 왼쪽: ⚙ 책갈피 설정, ↻ 다음 문장 · 오른쪽: 마지막 동기화 시각(24시간 넘으면 ⚠) |

**책갈피 설정** (⚙ 를 누르면 아래쪽에 작은 창. 바탕이나 `닫기` 를 누르면 닫힘, 설정은 기기에 기억)
- 보기 방식
  - `책 순서`(기본): 노트 파일명 날짜순(=읽은 순서)으로 한 책의 인용구를 적힌 순서대로. 보던 위치는 기기에 기억.
  - `무작위`: 섞인 순서로. ↻ 는 아무 문장, 다음 간격엔 원래 순서로.
- 바뀌는 간격: `5분` / `10분` / `30분` / `1시간`(기본). 07~18시 사이에만 바뀐다. 바꾸면 지금 문장부터 새 간격으로 이어진다.

**조작**
- 화면 탭: 지금 동기화
- 화면 길게 누르기: 관리 메뉴 (지금 동기화 / 화면 잔상 지우기 / 다시 불러오기 / 와이파이 설정 / 연결 파일 불러오기 / 연결 설정(직접 입력) / 기본 홈 화면 바꾸기 / 화면 자동 잠금 끄기 / 기기 설정)

전력 절약을 위해 화면은 매시 정각·30분에만 다시 계산하고(끝난 일정 걸러내기, 인용구 교체 — 간격을 30분보다 짧게 고르면 그 간격마다) 바뀐 칸만 다시 그린다. 주기적 자동 동기화는 하지 않는다(핫스팟 연결 순간·탭·매일 새벽에만). 책갈피는 동기화와 무관하게 받아 둔 인용구 안에서 바뀐다. 일정 칸 글자 크기는 고정이고, 책갈피는 인용구가 길면 글자가 줄어든다(최소 60%).

## 설치 (처음 한 번)

### 1. GitHub Pages
레포 **Settings → Pages** → `Deploy from a branch`, `main` / `(root)`.
확인: `https://nodeul99-dev.github.io/eink_dashboard/?demo=1`

### 2. Apps Script (구글 계정, PC에서)
1. https://script.google.com → 새 프로젝트 (`DS_CRO_대시보드`)
2. ⚙ 프로젝트 설정 → `appsscript.json 매니페스트 파일을 편집기에 표시` 체크
3. `Code.gs`, `appsscript.json` 을 이 레포 `apps_script/` 내용으로 통째로 교체 → 저장
4. `setupToken` 실행 → 권한 허용 → 로그의 TOKEN 메모
5. `listCalendars` 실행 → 업무 캘린더 이름 확인 → 스크립트 속성 `CALENDAR_NAME` 에 입력
6. `debugPayload` 실행 → 2주치 일정이 나오면 성공
7. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → `.../exec` URL 메모
8. 확인: 브라우저에서 `<웹앱 URL>?token=<TOKEN>` → `"events"` 가 보이면 성공

> 코드를 고친 뒤에는 **배포 관리 → 편집 → 버전: 새 버전**. URL은 그대로다.
> 'TOKEN을 모르면 아무것도 받을 수 없다'가 보안의 전부이므로 TOKEN은 남에게 보이지 않게.

### 3. Poke3 전용 앱
1. PC에서 APK 받기: `https://github.com/nodeul99-dev/eink_dashboard/releases/latest/download/eink-dashboard.apk`
2. USB(파일 전송)로 Poke3 `Download` 에 복사 → 파일 관리 앱에서 설치
3. 재부팅하면 기본 홈 앱 선택이 뜬다 → **DS_CRO_대시보드 → 항상**
4. BOOX 내비게이션 볼은 끈다 (제어 센터 또는 설정 → 내비게이션)
5. **연결:** PC 메모장에 `<웹앱 URL>?token=<TOKEN>` 한 줄 → `dashboard.txt` 로 저장 → USB로 Poke3 `Download` 에 복사
   → 화면 길게 누르기 → `연결 파일 불러오기` → 연결되면 `dashboard.txt` 는 지운다

> USB 파일 전송이 갑자기 느려지면 Poke3를 재부팅하고 바로 복사한다.
> 화면이 일부만 보이는 등 이상하면: 길게 누르기 → 화면 잔상 지우기 → 다시 불러오기 → 그래도 안 되면 재부팅.

### 4. 옵시디언 플러그인 (집 PC에서 한 번)
1. 볼트(`remote_hong`) 폴더의 `.obsidian/plugins/` 에 `eink-quotes` 폴더를 만든다 (숨긴 항목 표시 필요)
2. `obsidian_plugin/eink-quotes/` 의 `manifest.json`, `main.js` 를 넣는다
   (raw 주소에서 Ctrl+S: `https://raw.githubusercontent.com/nodeul99-dev/eink_dashboard/main/obsidian_plugin/eink-quotes/main.js` 등)
3. 설정 → 커뮤니티 플러그인 → 제한 모드 끄기 → ↻ → **DS_CRO 대시보드 인용구** 켜기
4. 플러그인 설정: `웹 앱 URL` 칸에 `<웹앱 URL>?token=<TOKEN>` 통째로 붙여 넣기(자동 분리), 폴더 `Books` → `보내기`
5. 다른 기기에 퍼지게: 각 기기 옵시디언 설정 → 동기화 → `설치된 커뮤니티 플러그인`, `활성 커뮤니티 플러그인 목록` 켜기

플러그인은 옵시디언을 켤 때, Books 노트를 고치고 1분 뒤, 명령 팔레트 `인용구 지금 보내기` 로 보낸다.
내용이 같으면 보내지 않고, 자동 전송 실패(오프라인·막힌 망)는 조용히 넘어간다.

### Poke3 기기 설정
- 충전기 상시 연결, 자동 절전·자동 종료 끄기
- **화면 자동 잠금 끄기:** BOOX 설정은 최장 30분이라, 길게 누르기 → `화면 자동 잠금 끄기` →
  '시스템 설정 수정' 허용을 켜고 돌아와 같은 메뉴를 한 번 더 누른다 (화면 꺼짐 시간을 약 24일로).
  앱이 떠 있는 동안은 wake lock 으로도 잠들지 않게 붙잡는다
- 아이폰 핫스팟: `다른 사람의 연결 허용` 켜기 (Poke3가 자동으로 다시 붙는다)
- ⚠️ 회사에 따라 사무실 안 개인 핫스팟 사용이 금지일 수 있다. 그렇다면 집·출근길에 동기화하고 회사에선 오프라인으로 쓴다(2주치를 받아 둔다).

**하루 루틴:** 출근 후 핫스팟 켜기 → 화면 한 번 탭 → 상태 줄이 '방금'이 되면 핫스팟 끄기.

## 인용구 추출 규칙 (`apps_script/Code.gs` `extractQuotes_`)
- 파일명 `2026-07-13 ● (독서) 죽도록 즐기기, 닐 포스트먼.md` → 책 `죽도록 즐기기`, 저자 `닐 포스트먼`
- 빈 줄로 나뉜 인용 블록(`>`) 하나 = 인용구 하나. 콜아웃(`> [!생각]` 등)은 제외
- `**굵게**`, `==형광펜==` 은 강조(화면에선 밑줄). 링크·이미지 등 나머지 마크다운은 걷어냄
- 300자 넘는 인용구는 건너뜀 (스크립트 속성 `QUOTE_MAX_CHARS`)
- 인용구는 스크립트 속성에 gzip 압축해 보관 (드라이브 권한 불필요, 수천 개까지)

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 상태 줄 `동기화 실패 (오프라인)` | 핫스팟 연결 후 화면 탭 |
| `unauthorized` | 기기에 넣은 TOKEN 이 스크립트 속성 TOKEN 과 같은지 → 연결 파일 다시 불러오기 |
| `work calendar not found` | 스크립트 속성 `CALENDAR_NAME` 철자 (`listCalendars`) |
| 인용구가 없음 | 플러그인 설정의 `보내기` 결과가 `노트 N개 → 인용구 M개` 인지 |
| 플러그인 `실패: HTTP 200` | Apps Script 실행 기록(≡▶)에서 `doPost` 오류 확인, 최신 코드로 새 버전 배포했는지 |
| 화면을 고쳤는데 그대로 | 길게 누르기 → 다시 불러오기 (인터넷 연결 상태에서) |
| Apps Script 를 고쳤는데 그대로 | 배포 관리 → 새 버전 으로 재배포 |
